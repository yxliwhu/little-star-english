# 小星星英语 · Kid’s Box 1

包含 Unit 1–12 的单元目录、听音找图、看词找图、口语示范、录音回放和故事屋。

106 张词卡、96 条口语提示、151 段课本原声、66 段教材视频，课本 p.4–93。

支持简体中文（普通话）、繁體中文（粵語）和 English，界面与互动提示同步切换。语言选择单独保存，切换保留学习进度。

互动提示、英语单词和跟读示范均采用预生成的豆包 TTS 2.0 / Vivi 2.0 配音：每种提示语言 15 段，210 段英语单词与短句（重复内容共用），合计 255 段 AI 配音。

孩子按住话筒录音，松开自动回放并记录一次表达尝试。录音最多 20 秒，首次麦克风授权后如已松手，会提示重新按住。数字句子按钮点按即播放示范，听音找图自动读题，并用耳机、话筒与回放图标提示操作顺序。浏览器限制自动回放时，可直接点击回放图标。

网页通过 audio-manifest.js 播放预先生成的文件；语音 API 密钥仅存本机，网页不调用收费接口。
教材来自家长提供的 Kid’s Box New Generation 1，供家庭学习。

网页端音视频已优化大小；完整本地版单独保留。学习记录仅保存在当前浏览器，各单元分别记录。录音只在当前页面回放，不上传，不做自动发音评分。

GitHub Pages：main 分支 / (root)，无需安装依赖或构建。
